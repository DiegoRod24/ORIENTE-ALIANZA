# ORIENTE-ALIANZA

PWA piloto para la experiencia de Tribuna Oriente: repertorio, modo tribuna en vivo, zonas, pedidos y orientación.

## Objetivo del MVP

- Preparar al hincha antes del partido.
- Mostrar el canto/acción activa durante el partido.
- Informar zonas y puntos de Oriente.
- Gestionar pedidos y retiro por QR en una siguiente etapa.
- Tener un panel administrador para controlar la experiencia.

## Stack

- React + Vite
- PWA instalable
- Supabase Realtime (siguiente integración)
- Cloudflare Pages

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

> Proyecto piloto no oficial. Antes de usar marcas, escudos, letras completas, cobros o indicaciones dentro del estadio, validar permisos y reglas aplicables.
